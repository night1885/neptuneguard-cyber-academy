# W05 — staff investigation review draft

Staff authoring guidance, not a protected deployed examination or calibrated grading scheme. Protect separately in delivery; store no learner identity, evidence or feedback in this repository.

## Review the method, not a preferred transcript

Use the [investigation brief](STANDALONE-WEB-W05-INVESTIGATION.md). Expect separate read/update investigations with exact starter/reference source identities. A passing reference is not a reproduction against the starter. Distinguish source predictions, actual in-process observations, simulated failures, proposed repairs and unattempted retests.

Require two causal hypotheses, nearest legitimate controls and an alternative explanation each. Course membership, object ownership, editable-field policy, SQL value binding and expected revision are independent questions. Correct classification needs source-to-effect reasoning, not merely naming mass assignment or access control.

## Effect and failure-stage evidence

Read findings should connect subject/resource facts, missing permission condition and returned fictional content. Update findings should inspect state/revision as well as response. A selected rollback failure and an error after a completed transaction can have different stored outcomes. Do not turn this distinction into an unexecuted claim about the fixture, concurrency, durability or a production retry policy.

Preserve positive and negative behavior under the correct contract. Reject-all, identity-specific fixes and changed expected results are not adequate repairs. Record narrow source diff, original predictions and actual failures/blockers honestly when later authorized.

## Independence and feedback

Assess reasoning, execution evidence and independence separately. An empty hint record is not proof that no help occurred. Record reference access and substantive hints separately from accessible presentation/support. Provide specific feedback and a reviewed resubmission process before formal use; no numeric threshold is set here.
