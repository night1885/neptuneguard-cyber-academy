# Foundation setup review — proposed instructor criteria

Maintainer/instructor draft for EH-LAB-00 through EH-LAB-02. Not a canonical lesson, calibrated grade/state, authorization adapter or published evidence workflow. Assessor-only notes belong outside eventual learner delivery. The current owner inspector is not a submission service.

## Milestone boundary
Review a reasoned, privacy-conscious setup record and honestly described installation/guest baseline. This is not the complete foundation investigation, professional assessment, programme or certificate. EH-LAB-03 through EH-LAB-05 retain their own scope/gates.

Check the actual brief and reviewed host/guest route first. Separate conceptual reasoning, observed execution, interventions and unperformed work. Fictional analysis and external credentials do not substitute for physical observations or current exercise authority.

| Area | Evidence sought | Insufficient substitute |
|---|---|---|
| Scope | Exact actions/targets, exclusions, stop/support/recovery process | Role, tool, private IP or old brief |
| Privacy | Minimal relevant/redacted host/guest record | Full reports, passwords, private keys |
| Compatibility | Exact OS/CPU/hypervisor/guest combination, documentation and separately recorded execution | 64-bit label, autodetection, untested matrix called approved |
| Capacity | Measured/planned values distinguished; two guests and host considered | Defaults called measured minima |
| Media | Exact release/image, independently established signing-key identity and genuine digest where executed | Historical keys/hashes, bare digest match or a success word |
| Configuration | All adapters/integrations reviewed before boot | Adapter 1 only, address label, failed ping |
| Baseline | Actual boot/login/tool observations; snapshot contents and faults | Snapshot existence called a tested restore |
| Explanation | Independent reasoning about host/guest, trust and observation limits | Memorized/invented output or hidden coaching |

These are review prompts, not numeric pass bands. Do not average away missing scope/privacy/setup controls. Use the actual incident process for a breach, not invented contacts or an aggregate score.

## Reviewer record
Use an approved private retention/review process or a synthetic rehearsal without real learner data. Record artifact revision, actual scope, observations, unobserved items, coaching, corrections and re-review basis. Do not collect entire images, credentials or unrelated personal files.

Requests for correction remain within existing authority; this draft issues no enrolment, assignment, practical permission or award. Resubmission/time limits, appeals and retention periods still require actual policy/calibration decisions.

## Honest checkpoint statement
State what was reviewed/executed, the exact route, remaining blockers and which separately authorized next activity may be considered. Do not write 'lab safe', 'certified', 'all isolated' or 'course complete' because a table is filled.

Before learner release: reproduce supported configurations and failure/recovery cases; approve tools/media/licensing/transfers; provide actual support/incident procedures; calibrate on original independent work; validate accessibility and private handling. No extra pilot/staging service is created, and owner browsing does not approve learner publication.
