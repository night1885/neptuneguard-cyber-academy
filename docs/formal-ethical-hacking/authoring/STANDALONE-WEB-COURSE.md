# Standalone web course — syllabus planning draft

Status: design only. W00–W08 are provisional planning labels, not canonical lesson IDs or a runtime course key. This document does not publish a course, validate vendor alignment or authorize practical activity.

## Independent entry and delivery

The course is independently selectable and completable from CPTS, OSCP and GPEN preparation. No enrollment in or completion of those courses is required. Necessary Linux, networking, HTTP/TLS and programming skills must be taught and assessed through this course's reviewed foundation bridge or established through reviewed equivalent skills.

Retain private Discord delivery with a separate course card and button-driven in-place navigation, including Back, Next, Save Progress and Resume Learning. Do not introduce learner slash-command or modal-driven course navigation. Enrollment, progress, evidence access, reviewer authority, lab permission, assessment, completion and awards remain course-specific. Shared teaching references do not transfer those states.

## Authoring and assessment gates

Each module still needs reviewed lessons, annotated demonstrations, tool/version assumptions, troubleshooting, guided work, independent variants and marking guidance. Teach the system model and trust assumptions before testing; require prediction, bounded observation, alternative explanations, impact analysis, repair where applicable, retest and communication of uncertainty. Fade hints as independence increases.

Every practical must specify machines/source/tools, starting baseline, topology, exact owned targets, permitted actions, resource limits, readiness checks, stop conditions, evidence minimization and reset/cleanup. Review licensing, costs, accessibility and lower-resource options. No public target, paid infrastructure, additional scanning or broader permission is authorized by this document.

Distinguish fictional demonstrations, synthetic tests and actual student observations. Page completion, a command result, another course's badge or an external exam does not alone establish independent competence. Set pass thresholds only after assessor calibration; no duration or pass rate is established here.

Before collecting learner evidence, define private storage, versioning, retention/deletion, reviewer access, access audit, repeated-action handling and recovery. Before activation, test re-entry, stale buttons, repeated clicks, concurrent updates, revoked access and saved-progress recovery. This document implements none of those controls.

## Certification and scope boundary

Advanced web-source analysis and OSWE preparation are intended curriculum directions, not validated objective coverage, endorsement, eligibility or exam-pass promises. A dated authoritative objective crosswalk, original assessment evidence, gap closure and independent review are required before claiming readiness.

CPTS, OSCP and GPEN preparation retain their existing structures and required web/API content. Other programme domains, student-built-lab requirements, Community Learning scope, canonical catalogue IDs, prerequisite graph and release standards remain unchanged. No runtime registry, application, database, workflow, learner record, permission, Discord message, deployment or award is changed.

All nine modules remain planning-level. This syllabus is not release evidence or a declaration of course completion.
