Status: authoring draft, not activated or assessed. This bridge adapts shared teaching references without importing another course's enrollment, progress, evidence rights, permissions or awards. No canonical ID or prerequisite edge is changed.

## Entry decision

After the W00 entry discussion, choose reviewed equivalent-skills assessment or in-course foundation teaching. Neither route requires CPTS, OSCP or GPEN enrollment/completion. Self-report, a badge or copied output alone is insufficient.

The shared [terminal lesson](../lessons/EH-LINUX-01.md) requires a clean learner guest from EH-LAB-02. Do not silently waive this setup requirement or send the learner to enroll in another course. Before practical delivery, provide the web course with reviewed equivalent guest-setup instruction and approval. That web-specific setup is not supplied by this document. If it is missing, keep execution blocked and continue with explanation/prediction only.

## Teaching sequence

1. Explain terminal versus shell, command name/options/arguments, and host versus guest. Ask the learner to identify what evidence would establish the intended guest and normal account. An uncertain context is a stop condition, not a reason to elevate privileges.
2. Work through the shared lesson's quoted filename example. Ask which text is one filename, which destination could be overwritten, and how a changed working directory affects a relative path.
3. Before each approved demonstration, obtain a prediction. Then compare actual observations with it. Discuss why silent comparison output needs interpretation alongside its status rather than treating all silence as success.
4. Use the original lesson's independent filename/copy task with fresh names and learner explanations. Keep the existing bounded operations and stop rules; add no installation, network action, elevated privilege or recursive cleanup.
5. Review a minimal private evidence excerpt and record substantive hints separately from access support. Preserve uncertainty instead of manufacturing expected output.

This draft adds no executable command block. The linked lesson remains draft material and may be used practically only after its existing setup, scope and evidence-handling conditions are reviewed for the web course.
