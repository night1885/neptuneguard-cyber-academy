A tiny correct policy repair does not equal OSWE-level source analysis. Basic Linux permissions do not equal privilege escalation. A connect check does not equal comprehensive enumeration. Paper cases and unit tests cannot replace implementation observations.

## Areas with no candidate lesson anchors in this review
K03 Windows foundations; K08 controlled exploitation; K09 Linux privilege escalation; K10 Windows privilege escalation; K11 AD/Kerberos; K12 pivoting/internal movement; K13 password representations and controlled testing; K15 custom web exploit chaining; K18 AWS; K19 Azure/Entra/federation; K20 bounded post-exploitation/C2; K21 client-side/endpoint-protection boundaries.

Each needs proposed outcomes, prerequisites, teaching, original exercises, constraints, provisioning/licensing review, positive/negative controls, independent assessment and an executed validation record. Publishing headings alone does not close a gap. Cloud and domain work must not prompt unapproved subscriptions, external connections or purchases.

## Prioritised large work packages
1. Foundations and design: reconcile full target inventories; deepen scripting; author Windows administration; establish supported lab candidates and the delivery-platform decision.
2. Professional technical pathway: reconnaissance/validation, controlled exploitation, Linux/Windows escalation, passwords, AD and internal assessment. Author and validate coherent prerequisite-linked practical groups, not isolated payload lists.
3. Specialist pathway: deeper web architecture/code tracing, advanced flaw analysis, custom exploit reliability, chaining and repair/retest.
4. Target extensions: explicitly review provider-specific cloud, identity, tool and endpoint topics instead of assuming overlap.
5. Independent performance: original professional and advanced-web capstones, report review, remediation handover and calibration.
6. Delivery/release: implement and validate the private workflow and actual student-built-lab journey in parallel with content; stage activation only after review.

These are proposed work packages, not scheduled or completed milestones. Owners, effort and dates remain to be agreed. A limited delivery rehearsal does not redefine the full programme as a short beginner course.
