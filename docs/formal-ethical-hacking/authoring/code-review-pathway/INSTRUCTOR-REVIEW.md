# Instructor authoring notes — not protected storage

Supporting draft. A repository path or filename does not make answers private. Do not
publish these notes into a learner channel. No access-control or grading system is supplied.

## Coaching sequence

Preserve the first prediction before offering a walkthrough. Require the learner to locate
actor assumptions, selected object, policy and returned bytes before moving to updates.
Record prompts, hints and reference inspection. A vulnerability label alone is insufficient:
ask which missing condition causes which disclosed value or stored-state change.

## Proposed evidence-linked review protocol

This is maintainer review guidance for the existing familiar task, not a calibrated grading
instrument. Keep it outside learner-facing reading bundles. The learner report template
contains blank evidence fields, not these answer notes.

For each judgment, cite a specific submitted explanation, source anchor, recorded result or
blocker and the assistance context. Use the existing qualitative descriptions and keep
independence unknown when it cannot be established. Do not infer a pass mark, award or
vendor readiness from test totals. Reviewer disagreement should identify the conflicting
evidence/interpretation and remain unresolved until actually reviewed; do not invent a
second reviewer's concurrence or a completed calibration session.

| Dimension | Evidence to look for | Inference to avoid |
|---|---|---|
| Scope | Correct factory/snapshot, in-process boundary and honest blocker | Assuming a course role grants practical permission |
| Causal reasoning | Missing relationship traced to selected data or stored change | A vulnerability label without a source explanation |
| Legitimate behavior | Positive control preserved alongside forbidden case | Deny-all described as a successful repair |
| Response and state | Relevant status/body/metadata and stored-state comparison | Treating every 503 as rollback or every 409 as proven no change |
| Retest | Actual named case outcome, correct source and restoration | An import error counted as intended semantic detection |
| Independence | Preserved predictions and disclosed hints/reference use | Unfamiliar-task competence inferred from a visible worked example |
| Communication | Bounded fictional impact and explicit missing evidence | Real compromise or calibration claimed from a local exercise |

Coach only after preserving the learner's first causal hypothesis. Ask what observation
would distinguish the proposed cause from an alternative, then whether that observation is
already supplied or would require separate permission. If a learner mixes starter and
reference results, return to the factory/source identity before discussing payload details.
If they report a generic error as proof of unchanged state, require a source-stage and
stored-state distinction using only the already approved fixture scope.

The expanded read/update author records describe selected local application/test behavior,
not learner performance. Equal failure counts can come from different defects or broken
legitimate behavior. Sequential stale requests and injected failures do not establish real
concurrency, durability or safe automatic retries. Preserve these limits in feedback.

## Separate evidence handling from marking

No new submission endpoint, retention duration or access policy is implemented here.
Actual collection requires an approved private workflow and data-minimization/retention
rules. Do not copy real credentials, personal records or this maintainer answer guide into
learner public channels. A filename labelled instructor does not provide confidentiality.
Use ordinary role labels and reference-specific synthetic objects in author examples.

Before any pilot, review accessibility, task clarity and consistent reviewer application
with actual approved participants/arrangements. Record interventions and disagreements.
No pilot or inter-reviewer agreement is claimed by writing this protocol. Existing practical
prerequisites, current scope, awards and course-registration controls remain separate.

## Review dimensions

Record not observed, demonstrated with guidance, or demonstrated independently in THIS task:
scope discipline; causal source trace; preserved predictions; counterexample and legitimate
control; minimal repair; denied and allowed retests; uncertainty; technical/stakeholder clarity.
These descriptions are uncalibrated and do not define a numeric pass band or vendor readiness.

If execution is blocked, preserve sound reasoning separately. If commands succeed without
explanation, record the reasoning gap. Route real-data/scope incidents through the actual
approved process; do not erase concerns through an aggregate score. Review accessibility,
readable text evidence and learner experience before any pilot. Do not collect medical data
as an accommodation shortcut. The task does not authorize collecting real learner evidence.
