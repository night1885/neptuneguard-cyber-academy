## Discussion keys and feedback

Local worksheet: 600/400 observations support a narrow mode-bit claim, not universal confidentiality or a tested denial. Useful output can coexist with an error; a later command's status does not recover a lost earlier status. Uncertain host/guest identity and an unfamiliar link call for stopping, not elevation or recursive changes. Ask what evidence would resolve uncertainty without expanding scope.

Network/HTTP worksheet: route selection, reachability, service behavior and permission are separate. HEAD representation length is not transferred response content. Status 200 is not proof of resource authorization. A redirect requires a scope decision before following it. Browser-to-proxy TLS does not establish downstream or at-rest protection.

Code worksheet: the original function returns False, True and True for the three guided pairs in order. Replacing or with and changes (0, False) from True to False and (7, True) from True to False. Synthetic parameters and flags do not verify actual events or reviewer identity. Require a trace rather than a memorized truth table. These answers have been reasoned through, not executed as tests in this batch.

## Independent assessment design

Before formal use, create fresh cases with equivalent difficulty and protected marking guidance. Require the learner to separate known facts, missing evidence, scope, next permitted action and uncertainty. For practical skills, obtain actual independent observations in the approved environment; paper answers alone are insufficient. Calibrate criteria with independent assessors before assigning a numerical pass threshold or claiming validated competence.
