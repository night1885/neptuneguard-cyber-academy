# Default-off reviewer report browser candidate

This source batch adds an unregistered owner-only browser for an explicitly selected learner. It publishes no entry message, lists no guild members, provisions no work/channel, collects no source, creates no production pool, performs no production migration or grants, and changes no startup wiring. Construction requires enabled: true and exclusively owned reviewer/discovery components.

The browser accepts only frr:list:<learnerId>:<page> buttons, with pages 0-4, from a bot-authored ephemeral origin in the exact configured application, guild and owner channel. It rejects self-targets. A route token selects a learner; it grants no authority. Each navigation freshly invokes the existing discovery service with the configured owner as actor. Discovery must retain its real core authorization path and trusted metadata reader. Opening report/feedback controls delegates to the existing owner handler, which must perform its own fresh authorization.

At most 20 candidates are considered and four report entries rendered per page. The browser emits references and revisions, never report/feedback bodies. It validates identifiers, unique report IDs, revisions, decisions and deadlines, clears stale controls on failures, disables mention parsing, and uses in-place updates only. A page is not a complete archive. A fixed owner channel and ephemeral origin are not substitutes for independent live channel-privacy verification.

Four unsettled browser operations and in-flight interaction-ID deduplication bound admission. No new timeout or cancellation guarantee is introduced. Disposal stops admission and disposes both owned components; drain waits for actual settlement, including delegated component work. Do not share these owned components with another lifecycle owner. Clearing this response does not erase prior replies or stored data.
