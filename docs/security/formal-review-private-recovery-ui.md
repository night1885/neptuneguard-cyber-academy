Recovery uses deferUpdate and editReply only. Missing update support or invalid origins perform no receipt lookup and use no reply/public fallback. Receipt views contain report reference, operation revision and original deadline, plus existing saved-report/feedback routes and a read-only refresh control. Mention parsing is disabled, embeds are cleared, and no report text, feedback, digest or operation key is rendered. A failed inspection clears controls only while the acknowledged private origin and actor remain valid. A failed acknowledgement is not followed by another acknowledgement.
